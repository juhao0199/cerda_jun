# V1.9.4.5.11 — Sunlit clean portfolio preview

Requires 1.9.4.5.10 (and the Sunlit brand refinement). The patch replaces only the preview's local stylesheet, removes redundant mock browser decoration, and retains the existing menu, reservation simulation, responsive morph, automatic playback and real website link. It does not overwrite sampled `sunlit-brand.json`, photo assets, the marketing hero or the workspace.

The presentation uses an intentionally light neutral canvas; the sampled CTA color and its foreground are retained. It is a responsive portfolio interpretation rather than an exact copy of the live restaurant website. Photos remain local. The dark ink is deliberate for legibility on the light canvas. No reservation is submitted. On mobile, the preview itself can scroll to accommodate the booking form. Reduced motion remains supported.

Run `npm --prefix frontend run typecheck`, `npm --prefix frontend run build`, and `npm --prefix frontend run test:e2e -- site.spec.ts --workers=1` after applying. Inspect Home, Menu and Visit in both viewport sizes, including the actual photo assets and sampled palette.
