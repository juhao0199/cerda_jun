# V1.9.4.5.12 — Adaptive marketing navigation

Marketing-only header, scoped CSS, light/dark transition at the hero boundary,
section-aware navigation, Solutions disclosure, mobile disclosure and preserved
scroll progress. No backend, global stylesheet or showcase changes.

The Solutions links target existing homepage anchors. Menu disclosures use native
buttons and links, close on Escape/outside pointer/focus or route changes, and
respect reduced motion. No automatic menu opening on hover.

Run `npm --prefix frontend run typecheck`, `npm --prefix frontend run build` and
`npm --prefix frontend run test:e2e -- navigation.spec.ts site.spec.ts --workers=1`.
