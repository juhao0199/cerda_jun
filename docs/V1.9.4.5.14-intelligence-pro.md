# V1.9.4.5.14 — Competitor Intelligence Pro

Requires V1.9.4.5.13 and all three network hotfixes (robots, DNS budget, DNS reuse). No schema migration or dependencies. Rebuild backend. Existing immutable reports remain readable.

- Select at most five HTML paths using discovered category diversity and shallow paths. Homepage is attempted first; no invented URLs or page redirects. Same robots, DNS, SSRF, TLS, request, byte and time limits as before. Categories are URL heuristics; discovery remains capped and may omit important sections.
- Prefer main/role=main; otherwise use a non-chrome fallback. Exclude identifiable nav/footer/aside/hidden/cookie markers. Global discovery links remain separate from main-content evidence. This is not a rendered DOM; hidden CSS, duplicate or JS-driven content may remain. Text is bounded to 20,000 characters and is not persisted; retain fingerprint, headings and evidence counts only.
- Alt review separates absent attribute, empty alt without explicit marker, explicitly decorative images and nonempty alt. Empty alt can be correct. Nonempty alt is not a quality guarantee.
- AEO and GEO add markup/adjacency signals, not official scores or evidence of AI citation. Priority review suggestions are based on competitor observations; inspect your own page before adopting them.
- Topic comparison includes published blog heading/title matches and a separate curated ten-section local homepage heading/label inventory, not a live render, full body inventory or direct SEO score comparison. Update OWN_SECTIONS when homepage headings change.
- Historical comparison is derived for the same hostname and analysis version, with the latest measured compatible report among the last 20 prior records. Only shared measured paths can be compared; newly sampled / not resampled do not imply creation/deletion. Text fingerprints reflect bounded samples, not semantic meaning.
- Legacy reports display the earlier measurement rules. Re-run twice to obtain comparable history. No AI Benchmark observations are created by scanning.

Tests: `docker compose exec backend python manage.py test apps.blog --verbosity=2`; `npm --prefix frontend run typecheck`; `npm --prefix frontend run build`; `npm --prefix frontend run test:e2e -- competitor-intelligence.spec.ts --workers=1`.
