# V1.9.4.5.7 — Sunlit Hotpot portfolio

Apply on top of V1.9.4.5.6. Only the Web Experiences portfolio showcase is changed. Its responsive motion, mounted page layers, manual controls, reduced-motion rules and local reservation review remain. The original marketing site, workspace and backend are not changed.

After applying, run `bash scripts/fetch-sunlit-showcase.sh` on macOS before starting Next.js. This downloads the ten public photos from the original Sunlit website and converts them to local JPEGs (maximum dimension 960 px). The script requires network access and macOS `sips`. No image files are bundled; no external image requests are made in the website itself. Only redistribute the photos if you have permission to use them in the portfolio. The website has a brand-text fallback if a local photo is missing.

Source: https://www.sunlit-hotpot-bkk.com/ — published restaurant details and menu highlights. No unverified menu prices, availability, client outcomes or actual booking submission. The interactive day/time options are demonstration choices, not available slots. The live website link leads to the restaurant's own website.

Run `npm --prefix frontend test`, `npm --prefix frontend run typecheck`, `npm --prefix frontend run build`, then `npm --prefix frontend run test:e2e -- site.spec.ts --workers=1` after stopping the dev server. Review Home, Menu, Visit and mobile autoplay with local photographs. Commit the intended public image assets along with the code after confirming portfolio permission.
