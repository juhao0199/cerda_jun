# V1.9.4.5.6 — Field / Table editorial preview

Baseline: V1.9.4.5.5. Only the Web Experiences example and its regression tests change. The original homepage, public navigation, existing 3D hero and other showcases are untouched.

- Original SVG food illustrations, stable responsive browser surface, editorial typography, real menu category and dish controls, and an interactive local reservation review. All content, prices, map and time selections are fictional examples; no reservation is created and no network request or personal data collection occurs.
- Nine-stage autoplay uses the existing viewport / document-visibility / reduced-motion gate. Direct manipulation pauses autoplay. Navigation indicator, retained page layers, artwork transitions and a review progress indicator use scoped CSS. Autoplay never claims to submit a booking.
- Responsive container layouts preserve a fixed preview height; smaller displays can scroll within the active panel. Inactive panels are inert and aria-hidden.
- No package install, backend restart or migration. Run `npm --prefix frontend test`, `npm --prefix frontend run typecheck`, `npm --prefix frontend run build`, and `npm --prefix frontend run test:e2e -- site.spec.ts --workers=1`.
