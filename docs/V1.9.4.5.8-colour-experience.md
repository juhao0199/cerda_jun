# V1.9.4.5.8 — Editorial colour experience

Requires V1.9.4.5.7 Sunlit showcase. Only additive public chapters and their tests are changed. The original marketing hero, estimator, inquiry flow, workspace and backend are not modified.

- Web: full-bleed Sunlit photography with a warm auburn and amber palette; removed the redundant ruler and outer window chrome. The compact control strip retains play/pause and device controls.
- Software: blue workspace, distinct stage colours and team accents. Existing FLIP project movement remains intact.
- AI: violet research surface, integrated question list and answer progress.
- Automation: teal signal path, amber human approval, green completion.
- Applications, engineering and FAQ: editorial colour accents and fewer nested panels.
- Photo movement pauses at its current phase. Existing reduced-motion and viewport controls remain.

Sunlit local JPEG files still need to be present (`bash scripts/fetch-sunlit-showcase.sh`, with permission to use the images). A missing photo is not a verified live image. No reservations are submitted. No dependencies or migrations required.

Run `npm --prefix frontend test`, `npm --prefix frontend run typecheck`, `npm --prefix frontend run build`, and `npm --prefix frontend run test:e2e -- site.spec.ts --workers=1` from the repository root. Check desktop/mobile rendering and actual motion in the browser. The added E2E test verifies distinct accents and preserved controls; full React runtime and FPS measurements require the local project.
